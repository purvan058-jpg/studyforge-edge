PROJECT TITLE
StudyForge Edge — Private On-Device AI Study Copilot

SHORT PROJECT DESCRIPTION (under 500 characters)
StudyForge Edge is a privacy-first AI study copilot designed for Snapdragon-powered Windows PCs. It converts lecture PDFs into exam-focused summaries, practice quizzes, revision plans and grounded Q&A using a local AI model through Qualcomm GenieX. The core workflow is designed to keep study material on-device, reducing cloud dependency while demonstrating practical NPU-powered generative AI.
